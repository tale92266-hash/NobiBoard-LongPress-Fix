## Build notes

- `page_align.py` takes TWO args (`<in> <out>`).
- uber-apk-signer 1.3.0: `-o <dir>` and `--overwrite` CONFLICT
  ("either provide out path or overwrite argument, cannot process both") —
  use `-o` only. First attempt printed help and left the out dir empty.
- **Lesson (new): `Instruction.toString()` does NOT include the referenced
  item in dexlib2 2.5.2** — a `contains("codePointAt")` check on it is
  VACUOUS (count 0 even though the invoke is there). The first run of
  ReplaceCWithFix11 failed on this (`codePointAt count=0 expected 1`).
  Fixed by checking the actual `ReferenceInstruction` refs
  (MethodReference name / StringReference value). The Stock Revert's
  equivalent marker check was vacuous for the same reason — it never
  actually verified anything. Always check refs, never toString().
